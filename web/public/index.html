espFace renderer host

An ESP32 describes its control UI in a few lines of Arduino code; the apps and this web renderer draw it.

DocumentationGetting started, concepts, API reference, widget catalogue, protocol. Flash a boardWrite a firmware image over USB from this browser (Chromium, WebSerial). Web rendererHow devices load /r/1/app.js and how to self-host it. Mobile appAndroid and iOS app: discovery, pairing, BLE, USB and Bluetooth transports.

Devices normally open the renderer themselves from their own http page; use this only for a device without the bootstrap page, e.g. the fake device on localhost:8080.

Renderer bundle: /r/1/app.js, pinned per protocol major. Source: manzari/espFace (MIT).
