espFace flash Web Serial, Chromium only, https

A convenience for blank boards: pick a firmware image, plug the ESP32 in over USB and flash it from the browser with esptool-js. Once espFace runs, use the OTA page of the device instead. Works in Chrome, Edge and other Chromium browsers; Firefox and Safari have no Web Serial.

This browser has no Web Serial API (or the page is not served over https).

1. Image

Use 0x10000 for an application image from PlatformIO or the Arduino IDE (firmware.bin, the same file the OTA page takes). A merged image that includes the bootloader and partition table (esptool merge_bin, Arduino "Export compiled binary" *.merged.bin) goes to 0x0. Unsure: a merged image is the safe choice on a blank board.

2. Device

Hold BOOT while plugging in if the board does not enter the bootloader by itself.
